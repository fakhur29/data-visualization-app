# Interactive Data Visualization Web App

An interactive data visualization tool built with Python and Streamlit. Upload any dataset and explore it through dynamic, customizable plots — no coding required.

## Features

- Upload any CSV dataset and explore it interactively
- Generate multiple chart types: scatter, bar, histogram, box, pair, and facet grid plots
- Real-time customization with session-state logic for a smooth experience
- Clean, modern interface with custom CSS styling

## Tech Stack

- **Python**
- **Streamlit** — web app framework
- **Pandas** — data handling
- **Seaborn** — statistical visualizations
- **CSS** — custom interface styling

## How It Works

1. Upload a dataset (CSV file)
2. Select the type of chart you want to generate
3. Customize axes, colors, and chart parameters in real time
4. Explore your data visually without writing any code
